# ScR-PrO

مساحة عمل شخصية (Monorepo) لتطوير أداة مساعدة مخصصة.

## هيكل المستودع

- `genesis/` — النسخة الأصلية المرجعية، لا يتم التعديل عليها.
- `lab/` — النسخة قيد التطوير المستمر (`gh0st.scr`).
- `samples/` — مساحة لرفع ملفات مرجعية من خمس بيئات مختلفة لتحليلها لاحقاً (`Jawal-host`, `tiger-host`, `foon-host`, `ucam-host`, `hyper-host`).
- `bookmarklet/` — روابط تفعيل بالنقر (bookmarklets) للنسخة الأصلية والنسخة قيد التطوير.
- `concepts/` — ملفات منقولة كما هي من مستودع شخصي آخر، لتكون مرجعاً للأفكار المستقبلية.

هذا المستودع خاص بالاستخدام الشخصي فقط.
