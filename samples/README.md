# samples/

مساحة خاصة لرفع ملفات النسخ الخمس المراد تحليلها لاحقاً لاستخراج الفروقات بينها قبل تطوير `lab/gh0st.scr`.

المجلدات الفرعية وحالتها:

- `Jawal-host/`: **تم الرفع والتحليل.** استُخرجت منها نتائج ودُمجت في `lab/gh0st.scr` كوحدة
  `ScriptPro.hosts.jawal` (راجع `lab/README.md` لتفاصيل النتائج، بما فيها اكتشاف أمني حول ملفي
  `shbab.js`/`shbab2.js`).
- `tiger-host/`: بانتظار الرفع.
- `foon-host/`: بانتظار الرفع.
- `ucam-host/`: بانتظار الرفع.
- `hyper-host/`: بانتظار الرفع.

> ملاحظة: `lab/gh0st.scr` أصبح الآن يتعرّف تلقائياً على النسخة الحالية (`ScriptPro.hosts`) ولا يُفعِّل
> إلا منطق النسخة المطابقة. عند رفع ملفات أي نسخة إضافية هنا، تُحلَّل ويُبنى منطقها الخاص كوحدة جديدة
> دون أي تعديل على وحدة جوال هوست القائمة.
