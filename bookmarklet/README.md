# bookmarklet/

روابط تفعيل بالنقر (Bookmarklet) تُضاف كمفضلة/علامة تبويب في المتصفح.

- `genesis.bookmarklet.js`: يحمّل وينفذ محتوى `genesis/original.js` مباشرة عبر fetch + eval.
- `lab.bookmarklet.js`: يحمّل وينفذ محتوى `lab/gh0st.scr` مباشرة عبر fetch + eval (يتحدث تلقائياً مع كل تعديل على الملف).

انسخ محتوى الملف المطلوب بالكامل (السطر الذي يبدأ بـ `javascript:`) والصقه كـ URL لمفضلة/bookmark جديدة في المتصفح.

## ملاحظة بخصوص امتداد الملف (js مقابل txt)

الرابط يعمل بنفس الطريقة تماماً سواء كان الامتداد `.js` أو `.txt`، لأن `raw.githubusercontent.com` يخدم أي ملف كنص خام (`text/plain`) بغض النظر عن امتداده، والمتصفح لا يقرأ الامتداد بل فقط المحتوى النصي الذي يمرّ إلى `eval`.

الفرق الوحيد عملي: تصفح المستودع نفسه. ملف بامتداد `.js` يظهر بتلوين كود واضح لأي زائر يتصفح المستودع، بينما ملف بامتداد `.txt` يظهر كنص عادي ويجذب انتباهاً أقل. إذا كانت الأولوية هي عدم لفت الانتباه عند تصفح المستودع، فامتداد `.txt` أنسب. إذا كانت الأولوية هي سهولة الصيانة والتمييز البصري للكود أثناء العمل عليه، فامتداد `.js` أنسب. تم اعتماد `.js` حالياً لسهولة الصيانة، ويمكن تغييره لاحقاً بسهولة دون كسر أي شيء.
